## Ubuntu 24.04 LTS (Noble Numbat) Cloud Micro

Minimal Ubuntu install built with minbase (a small set of essential packages) on an ext4 filesystem, paired with the Ubuntu VM-optimised kernel for improved compatibility and performance. New software can be added at any time using APT, Ubuntu's built-in package manager.
